| Màn hình / action | Operation |

| Public plans/list/detail | SUB-013/015 |
| Register/login/profile/refresh/logout | IDN-002/003/004/005/006 |
| Onboarding/profile/operations/members/logo/cover/legacy branch | BKR-005/006/007/009/019/020/021/022/023/033 |
| Categories CRUD | BKR-015/016/017/018 |
| Add-ons list/create/update/disable/image | BKR-010/011/012/013/014 |
| Products list/create/edit/options/media/publish/hide/archive | BKR-024/025/026/027/028/029/030/031/032 |
| Admin bakery list/detail/status | BKR-001/002/003 |
| Owner current/scheduled/orders/create/detail/payment/capability | SUB-008/009/010/011/012/014 |
| Admin payment list/approve/reject | SUB-001/002/003 |
| Admin plan list/create/edit/archive | SUB-004/005/006/007 |

- Public: Home/Explore/tiệm/chi tiết/gói → `live_public_pages.dart`, `live_subscription_pages.dart`. Query, sort, paging theo controller; không fallback fixture.
- Identity: `live_auth_pages.dart` → `LiveSession`. `Bearer`, `expiresIn` giây; refresh opaque trong HttpOnly cookie `refresh_token`, path `/api/v1/auth`; Max-Age/Secure giữ nguyên. Logout cần JWT + cookie.
- Owner: `live_owner_profile.dart`, `live_owner_catalog.dart` → `LiveBakeryRepository`. PUT operations/options thay thế đầy đủ, giữ ID server. Không đọc được options/ảnh draft sau restart: thông báo giới hạn và chặn PUT thiếu dữ liệu.
- Subscription/Admin: `live_subscription_pages.dart`, `live_payment_page.dart`, `live_admin_subscription.dart`, `live_admin_bakeries.dart`. Metadata JSON multipart `application/json`; proof ≤10 MiB. Tiền decimal, total từ server.
- UUID Idempotency-Key: create subscription order, submit payment, approve payment. Reject không có contract idempotency; không tự retry. Mutation khác không tự retry; kết quả chưa rõ cần đối chiếu read.
- Paging: `meta{page,pageSize,pages,total}` + `result`, page từ 1. Plans/categories/add-ons/members là array. Complete onboarding và DELETE trả 204 rỗng.

## Ranh giới và khoảng trống

Marketplace/RFQ/Offer, Product Order/Checkout/Review, Chat, Cake AI, Admin Users/Revenue/Settlement: **OUT_OF_SCOPE**. Live router không tới fixture repository. Thiếu API public sửa profile/address/reset password và discovery toàn bộ bakery của user: thông báo không khả dụng, không gọi `/internal/`.
